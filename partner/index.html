Server-Partner Gesucht!

Wir suchen ein aktives Minecraft-Netzwerk für eine gegenseitige NPC-Weiterleitung.

Das Konzept

Auf meinem Server (Empire): Im Spawn wird ein NPC mit deinem Skin & IP aufgestellt. Ein Klick leitet den Spieler per Transfer Packet direkt zu dir weiter.
Auf deinem Server: Du bietest eine offensichtliche Weiterleitung an. Z.B. als NPC bei der Modus-Auswahl, der Spieler direkt auf empire.dinushay.de leitet.

Die Anforderungen

  • Ein Netzwerk/Server mit einer aktiven Spielerschaft.
  • Der Haupt-Spielmodus darf kein SMP (Survival) sein.
  • Die Weiterleitung auf beiden Seiten muss zwingend über das Transfer Packet erfolgen.
